# vera-brain

Conceptual architecture for Vera's Noöplex synthetic brain family.

This repository separates three things that must not be conflated:

1. **Established science** — current neuroscience, neuromorphic engineering, biohybrid interfaces, microfluidics, materials, and quantum technologies.
2. **Engineering extrapolation** — components that are physically motivated but not currently demonstrated at full synthetic-brain scale.
3. **Wreckforge / Synthetic canon proposals** — in-universe system behavior that may exceed demonstrated present-day capability.

The current design lineage is:

- **HC-1 Noöplex** — synthetic hyperconnective neuroglial cognitive architecture.
- **HC-2 Noöplex-Q** — HC-1 plus dedicated quantum/photonic co-processing and quantum sensing.
- **HC-3 Noöplex-EQ** — HC-2 plus a synthetic neuroendocrine/interoceptive architecture for embodied human-like affect, volition modulation, and expressive behavior.

The architectural seed in `Architecture concept.md` remains authoritative for the repository's organizing idea: the brain is a system of interacting functional nodes rather than a pile of independent directories.

See `docs/architecture/` for the model lineage and `docs/science/` for evidence boundaries and technical grounding.
