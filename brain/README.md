# Hyperconnectome Brain Root

This directory is the structural expression of `Architecture concept.md`.

The HC brain is modeled as one distributed hyperconnectome whose specialized systems are represented as nodes. Nodes are not isolated mini-brains and are not human hemispheres. Each node owns a bounded functional domain while remaining densely coupled to other nodes through adaptive routing, shared state, and neuroplastic change.

The root is the whole brain. `nodes/` contains functional systems. `NODE_REGISTRY.yaml` is the canonical initial registry. `ROOT_CONTROL.md` defines coordination rules without inventing a homunculus or single seat of consciousness.

Identity-specific content does not belong here. This is a reusable template.
