# Node Layer

Every entry in `../NODE_REGISTRY.yaml` is a first-class functional node family in the initial HC template.

A node is defined by function, interfaces, state, learning rules, and routing relationships—not by a fixed human lobe or hemisphere. A node may be physically distributed, replicated, layered, or partially overlapping with other nodes while remaining logically distinct for architecture and diagnostics.

The initial registry preserves every functional area named in the original architecture seed and adds separations needed for a coherent system: identity continuity, language integration, interoception/homeostasis, affect, salience/attention, sensory integration, diagnostics/health, and explicit separation of routing from neuroplasticity.

Future node specifications should state at minimum: purpose, inputs, outputs, persistent state, transient state, learning/plasticity behavior, arbitration relationships, failure modes, and evidence status.
