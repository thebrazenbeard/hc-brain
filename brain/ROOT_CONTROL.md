# Root Control Model

The Hyperconnectome root coordinates but does not contain a single executive homunculus.

Root-level functions are distributed across routing, arbitration, salience, homeostasis, memory, volition, and self-model processes. The root provides shared addressing, state exchange, conflict arbitration, timing, health monitoring, and plasticity governance.

Core invariants:

- no hemispheric organization by default;
- no node is identical with the self or consciousness;
- nodes may specialize without becoming isolated;
- routing is adaptive and many-to-many;
- plasticity may alter edge strength, timing, recruitment, and effective topology;
- current memory and deep memory remain distinct;
- self-model and identity continuity remain distinct;
- sensory acquisition and interpretation remain distinct;
- affect, interoception, and homeostasis are systemic inputs to cognition rather than peripheral decorations;
- resolver/arbitration chooses among competing states without erasing unresolved conflict;
- embodiment is an interface layer, not the definition of the brain template.
